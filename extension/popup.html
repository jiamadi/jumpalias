JumpAlias

Settings & guideGive your pages memorable paths.

01Quick start

  1. Open the extension to fill in the current URL. Enter a path and press Enter to save.
  2. Enter the keyword in the address bar, press Tab or Space, type a path, then press Enter.

Spaces group paths into a tree. A parent can have its own URL and children.

02Personalize

Press j and Tab, then type a path such as dev github.

Tab and Space stay fixed. Keyword changes require a manifest reload.

Save current page

Shows Chrome's actual binding. Apply changes in Chrome settings.

Header buttons switch language and cycle System, Light and Dark.

Replace manifest.json in the extension folder with this file, then reload the extension. Tab and Space stay unchanged.

03Sync & backupChrome Sync

Use the same Google account, enable Chrome Sync, and install the same extension ID on each device.

  • Paths sync independently; newer revisions win for the same path.
  • Active devices confirm deletions. Devices inactive for over 30 days rebuild from cloud on return.
  • Import by pasting JSON; Export copies JSON to the clipboard.

Theme stays on this device. Sync has storage limits; no iCloud sync.

Supports https://, http://, chrome-extension://, chrome://
